::: tip Как устроена библиотека
Каждый алгоритм — отдельное пространство имён с `ensureLoaded()` и бизнес-функциями.
wasm разбит по алгоритмам: **загружается только тот, который вы вызываете**.
Один раз `await algo.ensureLoaded()`, дальше все вызовы синхронные.
:::
