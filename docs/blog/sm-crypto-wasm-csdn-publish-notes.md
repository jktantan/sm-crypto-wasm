## 评论区预备回答

- **“为什么不用 WebCrypto？”** 浏览器原生 `crypto.subtle` 普遍不支持国密，只能自实现。
- **“为什么不用 Rust？”** 见第二节；发布物形态、包体积、团队维护成本是主要考量。
- **“SM2 签名为什么只快 3.1×？”** 签名包含随机数、编码、门面层开销；验签的定宽大整数运算占比更高。
- **“数据可信吗？”** 同机、同参数、同消息；同进程交替 A/B；给出 `pnpm bench` 复现命令；SM2 有 ±20% 波动。
- **“能用于生产吗？”** 可以，但请按行业合规要求评估；库不做 RNG、证书链、HSM。
